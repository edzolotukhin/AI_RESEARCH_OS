## B. Production provider call path

```
ChunkedEvidenceExtractor.extract()
  └─ LlmEvidenceExtractor.extract()
       ├─ Prompt(system=..., user=source chunk + information_needs)
       ├─ LLMClient.generate(prompt)                    # NO options passed
       │    └─ OpenAIClient.generate()
       │         ├─ client.responses.create(
       │         │     model=config.llm_model,
       │         │     input=[system, user],
       │         │     max_output_tokens=config.llm_max_tokens,  # default 4096
       │         │     reasoning=...                          # ONLY if options.reasoning_effort set
       │         │  )
       │         └─ LLMResponse(
       │              content=response.output_text,
       │              finish_reason=_resolve_finish_reason(response),
       │              output_tokens, reasoning_tokens,
       │              incomplete_reason, max_output_tokens, ...
       │            )
       ├─ ResponseShapeDiagnostics.from_response_content(response.content)  # metadata discarded
       └─ _parse_payload(response.content)
            └─ JsonExtractor.extract_all → JsonValidator.validate
                 └─ ValueError("LLM evidence payload must be a JSON object") on failure
```

### Layer table

| Layer | Class / function | Input | Output | Failure handling |
|-------|------------------|-------|--------|------------------|
| Evidence wrapper | `ChunkedEvidenceExtractor.extract` | source chunks | candidates / diagnostics | catches inner exceptions → `extractor_status=exception`, continues |
| Extractor | `LlmEvidenceExtractor.extract` | source, design, run_context | `list[EvidenceCandidate]` | LLM errors → `EvidenceConfigurationError`; parse errors → publish shape + re-raise `ValueError` |
| LLM interface | `LLMClient.generate` | `Prompt`, optional `LLMGenerationOptions` | `LLMResponse` | abstract |
| Provider adapter | `OpenAIClient.generate` | prompt, options | `LLMResponse` | SDK exceptions propagate |
| SDK call | `client.responses.create` | model, input, max_output_tokens, optional reasoning | SDK response object | SDK/network errors propagate |
| Normalization | `OpenAIClient._resolve_*` | SDK response | finish_reason, tokens, incomplete_reason | partial — only selected fields |
| Shape diagnostics | `ResponseShapeDiagnostics.from_response_content` | content string only | shape dict | always `provider_response_received=True` if generate succeeded |
| Parser | `LlmEvidenceExtractor._parse_payload` | content string | dict payload | `ValueError` single message for all parse failures |

## D. Provider response normalization

### Fields consumed by `OpenAIClient`

| Provider field (SDK response) | Consumed? | Mapped to |
|------------------------------|-----------|-----------|
| `output_text` | **YES** | `LLMResponse.content` |
| `status` | partial | `finish_reason` via `_resolve_finish_reason` |
| `incomplete_details.reason` | **YES** | `finish_reason` (max_output_tokens→length), `incomplete_reason` |
| `usage.output_tokens` | **YES** | `LLMResponse.output_tokens` |
| `usage.output_tokens_details.reasoning_tokens` | **YES** | `LLMResponse.reasoning_tokens` |
| request `max_output_tokens` | **YES** | `LLMResponse.max_output_tokens` |
| request `reasoning.effort` | **YES** | `LLMResponse.configured_reasoning_effort` |

### Fields discarded (not mapped to `LLMResponse`)

| Provider field | Diagnostically useful? |
|----------------|------------------------|
| Raw `status` string (when incomplete_details absent) | YES |
| Full `output` item array | YES — alternative text locations |
| Individual output item types (message, reasoning, refusal) | YES |
| Response ID | YES — support correlation |
| Input token usage | YES — cost/debug |
| Refusal objects | YES |
| Content filter metadata | YES |
| Error objects embedded in response | YES |

### Provider → LLMResponse conceptual map

```
OpenAI Responses API response
  status=completed          → finish_reason="stop", incomplete_reason=None
  status=incomplete         → finish_reason=reason or status
  incomplete_details.reason=max_output_tokens → finish_reason="length"
  output_text               → content (may be "", partial JSON, or complete JSON)
  usage.output_tokens       → output_tokens
  usage...reasoning_tokens  → reasoning_tokens
  [everything else]         → DISCARDED
```

**Evidence path uses only `content`.** All completion metadata on `LLMResponse` is available in-process but **never reaches P1-07.4.1 diagnostics**.

## F. Incomplete JSON paths

### Mechanism (PROVEN FROM CODE)

1. Provider returns partial `output_text` beginning with valid JSON object opener.
2. `JsonExtractor._find_root_container_end` returns `None` (unbalanced braces).
3. Extractor appends `text[index:]` as sole candidate (truncated tail).
4. `JsonValidator.validate` fails `json.loads`.
5. `parsed_root_type=no_valid_json`, `json_container_count=1`.
6. `_parse_payload` raises same `ValueError` as empty/malformed cases.

**Application truncation before parser:** **IMPOSSIBLE** — `response.content` is passed verbatim.  
**Preview truncation:** Only affects `response_preview` (800 chars); does NOT affect parsing.

### Live q1/q3 consistency

| Observation | Consistent with |
|-------------|-----------------|
| response_text_length > 0 | Non-empty provider output |
| preview starts `{"items":[` | Valid JSON prefix |
| json_container_count = 1 | Unclosed root container appended |
| parsed_root_type = no_valid_json | Validator rejected truncated candidate |
| Same pattern in run d89ec4ff (lengths 1261, 520) | Recurring failure mode |

### Completion metadata (NOT in persisted live data)

Repository code maps `status=incomplete` + `incomplete_details.reason=max_output_tokens` → `finish_reason=length`, `was_truncated=True`.  
Planner path already uses this pattern (`test_openai_client_reasoning.py`).  
Evidence path **does not persist or act on** these fields.

| Hypothesis | Rank | Basis |
|------------|------|-------|
| Provider incomplete / max_output_tokens truncation | **1 — STRONGLY INDICATED** | Identical shape to offline incomplete fixture; prior run high reasoning_tokens; no app truncation |
| Model returned malformed JSON on normal completion | **2 — POSSIBLE** | Cannot exclude without provider metadata |
| Application truncation | **3 — DISPROVEN** | Code audit |
| Preview truncation only | **N/A** | Diagnostic display only |
