## Property T

A successfully fetched topic-relevant XLSX Source is converted into deterministic,
bounded, human-readable `Source.content_text` such that:

1. quantitative values retain metric / header / geography / time context;
2. existing Evidence extraction consumes the text unchanged;
3. existing grounding verifies `source_excerpt` as a substring of `content_text`;
4. no new LLM stage is introduced;
5. downstream remains file-format agnostic.

---

## Architecture

```
HttpSourceRetriever.retrieve
  ├─ HTML / plain text → existing path
  ├─ XLSX MIME (or defensive .xlsx + octet-stream) → extract_xlsx_text
  ├─ .xls / .xlsb / .ods → unsupported_spreadsheet_format
  └─ PDF / other → unchanged unsupported
```

New component: `infrastructure/retrieval/xlsx_text_extractor.py`
Dependency: `openpyxl>=3.1,<4` (infrastructure only).

---

## Rendering contract

- Sheet banner: `[Sheet: <name>]`
- Table rows: `Sheet="<name>" | <header>=<value> | ...`
- Multi-row headers composed with ` / `
- Visible sheets only; workbook order
- Bounds: 20 sheets / 500 rows / 40 cols / 200_000 chars
- Truncation sets `workbook_truncated=true` and may yield `TRUNCATED`
