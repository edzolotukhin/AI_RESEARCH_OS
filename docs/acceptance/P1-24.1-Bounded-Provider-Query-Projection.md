# P1-24.1 — Bounded Provider Query Projection (PROPERTY AA)

## A. Executive verdict

PASS. A deterministic, bounded, transient provider-query projection now preserves category, geography, and core InformationNeed intent while leaving the durable SearchQuery contract intact. The recorded P1-23.2 replay shrinks from 367.17 to 133.17 average characters (63.73%) and retains category/geography in 12/12 queries. No provider, LLM, budget, persistence, API, or UI behavior was invoked or expanded.

## B. PROPERTY AA

The complete internal SearchQuery remains the semantic/audit record. A provider-facing query is derived from structured research semantics and used only at provider execution. Unsafe projection fails open to the complete query.

## C. Exact old provider query path

`SearchQueryBuilder/TargetedSearchQueryBuilder -> SearchQuery.query_text -> SourceAcquisitionService._collect_candidates -> TavilySearchProvider.search -> payload["query"] = query.query_text`.

## D. Exact new provider query path

`SearchQueryBuilder/TargetedSearchQueryBuilder -> project_provider_query_text -> transient SearchQuery.provider_query_text -> SourceAcquisitionService._collect_candidates -> TavilySearchProvider.search -> payload["query"] = provider_query_text or query_text`.

## E. Internal SearchQuery preservation proof

`query_text` construction is unchanged and CASE 1 compares the complete initial-query texts. `provider_query_text` is frozen with the record but deliberately omitted from `to_dict`/`from_dict`; the persisted/API shape therefore remains unchanged.

## F. Projection algorithm

Normalize structured units; require non-empty category, geography, and core intent; shorten geography at subordinate `;`/`(` detail; keep the first complete intent sentence; assemble category -> geography -> intent; add a complete targeted intent when it fits; add a complete explicit-year timeframe when useful and it fits; cap at 220 characters without slicing a semantic unit.

## G. Structured inputs used

Canonical Brief/design category from `resolve_category_subject`, InformationNeed geography, InformationNeed description, useful timeframe, and (for targeted base queries) the first resolved missing-aspect semantic target.

## H. Fail-open conditions

Missing category, geography, or core intent; an empty normalized result; or required units exceeding 220 characters. The adapter then submits the complete `query_text` without crashing.

## I. Initial Search integration

`application/sources/search_query_builder.py` derives one projection for every initial query. The number and durable text of queries are unchanged.

## J. Targeted Search integration

`application/research_quality/targeted_search_query_builder.py` applies the same projection to the targeted base query and preserves a resolved missing-aspect target when it fits.

## K. Remediation integration

Directive/remediation queries use the same projector with category, geography, directive intent, and timeframe. No separate remediation policy or extra call was introduced.

## L. Tavily adapter behavior

Only payload query selection changed: `query.provider_query_text or query.query_text`. API URL, authentication, `max_results`, response normalization, ranks, scores, and errors are unchanged.
