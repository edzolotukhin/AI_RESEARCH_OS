# Quantitative Reference Studies

## Purpose

Quantitative Reference-Study Validation tests whether the mature quantitative architecture produces trustworthy outcomes on real studies.

## Reference study principle

Each study should preserve:

1. Research Design.
2. Questionnaire/codebook measurement authority.
3. Analysis Plan correctness.
4. Numerical correctness.
5. Finding semantic context.
6. Insight support constraints.
7. Report support integrity.
8. Truthful Objectives/Sufficiency.
9. A reproducible final outcome.

## Blindness principle

Human professional reference output is `POST_FREEZE_ONLY`. Legitimate study inputs may include the questionnaire, respondent dataset, and study metadata. Human report content must remain inaccessible until `AI_OUTPUT_FROZEN` and legitimate Phase-B unlock.

## Numerical authority

The source dataset is primary numerical authority. The human report is a professional analytical reference, not an infallible numeric oracle. The Structured Analytical View (SAV) is the primary numeric output evaluated by the platform.

## Acceptance flow

Input assets → deterministic authority → semantic authority → terminal outcome → restart proof → Phase-A freeze → Phase-B human comparison.

The repository record captures only neutral identities, execution facts, immutable fingerprints, bounded-gap classifications, and verdicts. Detailed evidence and private materials remain externally governed.

## Cross-study purpose

One successful internal contract is insufficient. The platform should be validated across materially different study types, using the same neutral record structure so recurring and study-specific gaps can be distinguished without changing prior records.

## Frozen architecture principle

Do not open new hardening milestones merely to discover theoretical boundary conditions. A production hardening milestone requires a demonstrated defect from real acceptance evidence. Reference-study governance itself does not authorize production or test changes.

## Private-asset rule

Private questionnaires, respondent datasets, human reports, durable roots, extracted gold-reference content, private benchmark harnesses, and temporary study suites remain external and private unless separately approved. Their contents, identifying values, local paths, and answer-key material must not be committed here.
