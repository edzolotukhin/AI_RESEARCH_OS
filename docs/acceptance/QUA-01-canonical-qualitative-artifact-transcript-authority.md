# QUA-01 local acceptance

## Implemented workflows

`QUALITATIVE/1 — In-Depth Interviews` is registered as CMF `transcript_authority`. Both production actions converge on canonical Transcript Version:

- prepared DOCX/TXT: private immutable upload → bounded parser → exact segments/spans → readiness → persisted DOCX export;
- audio: private immutable upload → queued job → existing worker loop → deterministic provider result → canonical transcript with timing → readiness → persisted DOCX export.

Prepared acceptance contains no audio record, invokes no transcription provider and preserves absent timestamps. Audio acceptance uses the deterministic adapter, preserves diarized label/role and timing, and makes no external call.

## Integrity evidence

Artifacts verify byte size and SHA-256 checksum. Transcript correction creates V2 with exact V1 parent and leaves V1 text/spans unchanged. Stable span tests reject changed checksums, foreign segments and out-of-range bounds. Provider results are bound to exact job/artifact. Existing transcript lookup fences worker retry after canonical persistence. Consent withdrawal fails readiness closed.

DOCX import/export round-trip preserves transcript text and segment/speaker order. Imported bytes and generated bytes are intentionally different artifacts. Generated bytes are stored once; repeated and post-restart downloads are identical.

Server-side Project ownership precedes participant/session/artifact/job/transcript/export access. Project/run/session and source-artifact relationships are validated. Unsupported media, invalid DOCX, incomplete timings, duplicate segments, stale spans and destructive V2 creation fail closed.

## Provider isolation and limitations

OpenAI, Tavily, ARK, AssemblyAI and all external transcription providers were not called. AssemblyAI live verification is not required and was not performed. Speaker-label interpretation remains bounded and unknown labels stay unknown. Automated clean generation, Coding, Themes, Findings, Insights, Review and final Qual deliverables are not implemented by design.
