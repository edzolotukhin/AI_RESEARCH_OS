## D. Final ResearchRunResult contract

```
ResearchRunResult
  run_id, project_id, correlation_id?
  workflow_status
  outcome: ResearchRunOutcome
  readiness: ReadinessProjection
  termination_reason
  limitations[]
  budget_usage: BudgetUsageProjection  # available|partial
  source_summary / evidence_summary / finding_summary / insight_summary
    {count, ids[], items[{id, statement?, source_id?}], acquired/failed/truncated?}
  latest_report?: ReportProjection
  latest_review?: ReviewProjection
  artifact_status: ArtifactStatusProjection
  provenance_summary: ProvenanceSummary
```

Summary-first: no `content_text`, no bulk `source_excerpt` dump.

## E. ResearchRunOutcome mapping table

| Outcome | Rule |
|---|---|
| **APPROVED** | Approved artifact exists **and** supporting Review `approve` for that report |
| **QUALITY_REJECTED** | No approved artifact; latest review is `reject`, or `revise` with rejected artifact / failed review task / failed workflow |
| **NOT_READY** | Readiness task **completed**; `ready_for_analysis=false` or `research_outcome=insufficient_research`; workflow **completed**; analyze/report/review skipped; no approved artifact |
| **EXECUTION_FAILED** | Workflow `failed`/`cancelled` not explained by quality rejection or NOT_READY (e.g. readiness task hard-fail) |

Fail-closed (`ResearchRunResultProjectionError`) on contradictory state
(e.g. approved artifact without approve review; approve review without approved artifact;
ambiguous completed-ready without deliverable).

Workflow status alone never determines product outcome.
